# Social Feed Block for OJS 3.5

A sidebar block that shows the latest posts of a Mastodon or Bluesky account
(or a Mastodon hashtag, or a Bluesky custom feed) on your journal's pages.

The server fetches and caches the posts, and the block renders plain HTML.
Visitors' browsers never connect to Mastodon or Bluesky, no third-party script
or image is loaded and no cookie is set.

Status: under development.
